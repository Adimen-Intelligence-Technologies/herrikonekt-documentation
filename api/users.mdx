The Users API provides endpoints to retrieve and update the authenticated user's profile and account information. All requests must include a valid API key in the `Authorization` header.

## GET /users/me

Retrieve the authenticated user's profile.

**Request**

```bash
curl -X GET https://api.adimen.ai/v1/users/me \
  -H "Authorization: Bearer YOUR_API_KEY"
```

**Response (200)**

```json
{
  "id": "usr_01hxyz123abc",
  "email": "user@example.com",
  "display_name": "Jane Smith",
  "plan": "pro",
  "created_at": "2024-01-15T10:30:00Z",
  "language": "en",
  "region": "US",
  "avatar_url": "https://cdn.adimen.ai/avatars/usr_01hxyz123abc.jpg"
}
```

<ResponseField name="id" type="string">
  The unique identifier for the user account.
</ResponseField>

<ResponseField name="email" type="string">
  The email address associated with the user's account.
</ResponseField>

<ResponseField name="display_name" type="string">
  The user's chosen display name shown across the Adimen AI interface.
</ResponseField>

<ResponseField name="plan" type="string">
  The user's current subscription plan. Possible values: `free`, `pro`, `business`.
</ResponseField>

<ResponseField name="created_at" type="string">
  The ISO 8601 timestamp indicating when the account was created.
</ResponseField>

<ResponseField name="language" type="string">
  The user's preferred language, expressed as a BCP 47 language code (e.g. `en`, `fr`, `de`).
</ResponseField>

<ResponseField name="region" type="string">
  The user's region, expressed as an ISO 3166-1 alpha-2 country code (e.g. `US`, `GB`, `DE`).
</ResponseField>

<ResponseField name="avatar_url" type="string">
  A URL pointing to the user's avatar image. Returns `null` if no avatar has been set.
</ResponseField>

---

## PATCH /users/me

Update the authenticated user's profile.

**Request Body**

<ParamField body="display_name" type="string">
  The new display name to set for the user. Must be between 1 and 100 characters.
</ParamField>

<ParamField body="language" type="string">
  The preferred language for AI responses, expressed as a BCP 47 language code (e.g. `en`, `es`, `ja`).
</ParamField>

<ParamField body="region" type="string">
  The user's region, expressed as an ISO 3166-1 alpha-2 country code (e.g. `US`, `CA`, `AU`).
</ParamField>

**Request**

```bash
curl -X PATCH https://api.adimen.ai/v1/users/me \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"display_name": "Jane Smith", "language": "en"}'
```

**Response (200)**

Returns the updated user object using the same schema as `GET /users/me`.

```json
{
  "id": "usr_01hxyz123abc",
  "email": "user@example.com",
  "display_name": "Jane Smith",
  "plan": "pro",
  "created_at": "2024-01-15T10:30:00Z",
  "language": "en",
  "region": "US",
  "avatar_url": "https://cdn.adimen.ai/avatars/usr_01hxyz123abc.jpg"
}
```

<Note>
  Your `email` and `plan` cannot be changed through the API. To update your email address, visit your account settings in the Adimen AI app. To change your plan, visit the billing page.
</Note>
