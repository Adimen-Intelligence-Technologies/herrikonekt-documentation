title: "Sessions API: Create and Manage AI Conversation Sessions"

---

Sessions represent individual AI conversation contexts. Each session maintains message history and context for up to 24 hours of inactivity, allowing Adimen AI to carry forward what was discussed earlier in a conversation. Once a session expires, its context is no longer available for new queries.

## GET /sessions

List all active sessions for the authenticated user.

**Query Parameters**

<ParamField query="limit" type="integer">
  The maximum number of sessions to return per page. Defaults to `20`. Maximum value is `100`.
</ParamField>

<ParamField query="offset" type="integer">
  The number of sessions to skip before returning results. Use this for pagination. Defaults to `0`.
</ParamField>

<ParamField query="status" type="string">
  Filter sessions by status. Accepted values: `active`, `expired`, `all`. Defaults to `active`.
</ParamField>

**Request**

```bash
curl -X GET "https://api.adimen.ai/v1/sessions?limit=10&status=active" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

**Response (200)**

```json
{
  "sessions": [
    {
      "id": "ses_01abc123xyz",
      "status": "active",
      "created_at": "2024-06-01T09:00:00Z",
      "last_activity_at": "2024-06-01T09:45:00Z",
      "message_count": 12
    }
  ],
  "total": 1,
  "limit": 10,
  "offset": 0
}
```

## POST /sessions

Create a new AI session.

**Request Body**

<ParamField body="context" type="string">
  An optional system-level instruction or context that guides the AI's behavior for the entire session (e.g. `"You are helping the user plan a product launch."`). If omitted, the session uses Adimen AI's default behavior.
</ParamField>

**Request**

```bash
curl -X POST https://api.adimen.ai/v1/sessions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"context": "You are helping the user plan a product launch."}'
```

**Response (201)**

```json
{
  "id": "ses_01new456abc",
  "status": "active",
  "created_at": "2024-06-01T10:00:00Z",
  "last_activity_at": "2024-06-01T10:00:00Z",
  "message_count": 0
}
```

---

## DELETE /sessions/{id}

Delete a session and all of its message history.

**Path Parameters**

<ParamField path="id" type="string" required>
  The unique identifier of the session to delete (e.g. `ses_01abc123xyz`).
</ParamField>

**Request**

```bash
curl -X DELETE https://api.adimen.ai/v1/sessions/ses_01abc123xyz \
  -H "Authorization: Bearer YOUR_API_KEY"
```

**Response:** `204 No Content`

<Warning>
  Deleting a session permanently removes all message history associated with it. This action cannot be undone. Make sure you no longer need the session's conversation history before proceeding.
</Warning>
